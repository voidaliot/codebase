# Support for Aliot Codebase

Read the [user guide](docs/user-guide.md) for diagram workflows and settings,
or [language setup](docs/languages.md) for extensions, syntax tools and limits.

Report bugs, request features and ask questions in
[Codebase issues](https://github.com/voidaliot/codebase/issues).

For a bug report, include:

- Aliot Codebase and VS Code versions, operating system, and whether you use SSH,
  WSL or a container.
- The language, diagram view and relevant language extensions.
- Steps to reproduce, the expected result and what happened instead.
- A small example or screenshot, plus any relevant Language health or diagram notes.

Use a minimal example you can share publicly. Remove credentials, personal data
and confidential source from screenshots and logs before posting.

This repository hosts public documentation, artwork and issue reports.
The extension's development source is maintained privately.
